# Central de Configurações (`/settings`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar a central administrativa de configurações (`/settings`) estruturada em 5 abas (Geral da Loja, Mesas & Salão, Segurança, Assinatura e Zona de Perigo), com ações de backend seguras para atualização de dados, ajuste de capacidade de mesas, troca de senha, cancelamento de plano no Asaas e encerramento de conta.

**Architecture:** Server Component em `app/(app)/settings/page.tsx` lendo `searchParams.tab`. Server Actions dedicadas em `actions/settings.ts` com validação Zod e travas operacionais. Componentes clientes modulares para cada aba com aba ativa em âmbar (`#F59E0B`) e texto branco.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Lucide React, Appwrite (`node-appwrite`), Asaas API, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-05-settings-design.md`

## Global Constraints

- Anti-AI Slop: sem badges desnecessárias, sem gradientes saturados, zero emojis em labels ou mensagens.
- Paleta: superfícies neutras (`#FFFFFF`, `#F4F4F5`, bordas `#E4E4E7`), textos em `#121212`, destaque em âmbar (`#F59E0B`). Botões ativos das abas em fundo âmbar e texto branco (`bg-amber-500 text-white`).
- Trava de Segurança no Salão: bloqueia redução de mesas caso as mesas excedentes possuam comanda aberta (`status !== 'idle'`).
- Zona de Perigo Responsável: cancela assinatura recorrente no Asaas ao desativar conta para prevenir cobranças futuras.

## Review Focus

- Redução de mesas ocupadas: rejeição com mensagem explicativa ao lojista.
- Aumento de capacidade: reativa mesas já existentes inativas sem recriar tokens.
- Troca de senha: senha atual validada no Appwrite antes de atualizar.
- Cancelamento Asaas: tratamento de erro de rede sem corromper estado local.
- Exclusão de conta: verificação do nome exato do estabelecimento antes de desativar.
